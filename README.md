# Serviço Certo

> Sistema de Ordens de Serviço para pequenos negócios.

O **Serviço Certo** é um projeto pessoal em desenvolvimento com o objetivo de ajudar pequenos negócios a organizarem sua operação em um só lugar: registrar os serviços prestados, emitir nota e fazer a gestão do estoque.

## Objetivos

- **Ordens de Serviço** — registre os serviços prestados de forma simples e organizada.
- **Emissão de nota** — agilize a documentação dos serviços realizados.
- **Gestão de estoque** — acompanhe entradas, saídas e disponibilidade de itens.

## Status do projeto

O projeto está **no início**. Ainda não há código publicado — este repositório marca o começo da caminhada e vai evoluir em público.

Acompanhe as atualizações por aqui. Ideias e sugestões são muito bem-vindas!
